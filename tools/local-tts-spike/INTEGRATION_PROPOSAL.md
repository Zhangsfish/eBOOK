# S02B 接口与本地资源生命周期提案（尚未实施）

本文件是 S02A 要求的设计输入，不是进入 S02B。当前 App 没有修改；只有在
原生 iOS 推理、资源/许可证和独立审查门槛解决后，才实施用户可见集成。

## 单模型与四个声音

系统中文始终可用；AI 女声 A、女声 B、男声 C 分别映射 3、4、58，共用一个
已验证 Kokoro 引擎和一份资源。模型构造/合成串行执行，不能每个声音都建一份。
界面不暴露上游 103 个 speaker 技术编号，也不需要账号、付费、Key 或服务端。

窄接口示意：`LocalTTSProvider.synthesize(chunk, voice, synthesisRate, cancellation)`
返回本地 PCM/WAV、实际 sampleRate/帧数、模型/设置指纹和原始文本 anchor。
正文由本机阅读分块层提供，不传给下载器或任何网络服务。每次 <=240 Unicode
scalars，在句/段边界切分；保存稳定 UTF-16 范围以衔接现有阅读位置。

合成速度默认 1.0，传入模型并持久化用户设置；本阶段只实测 1.0。不得同时把
同一个“倍速”重复应用到合成和播放器。以后调速/换声使旧预取缓存失效，已听
位置保持；未实测的速度不标为产品验收通过。

## 一次显式下载

选 AI 声音才显示一次可选下载确认，告知实测归档约 147 MB、解包约 215 MB，
临时解包/保留归档需要额外空间；最终手机安装占用还要计原生库，当前未测。
Wi-Fi 优先，蜂窝网络另行明确选择；阅读和系统朗读不依赖下载完成。

仅允许固定 HTTPS 来源和版本化 manifest；下载完整归档 SHA 校验、严格成员/
尺寸/路径/链接检查、逐文件校验后，原子提升为 `verified`。下载器不收正文。
状态机：`absent -> downloading -> verifying -> ready`，失败/取消为可恢复状态；
恢复信息和 `.part` 不得冒充 ready。使用 URLSession 的恢复数据/Range 时核对
服务器 ETag/长度/版本；不兼容或版本变更则显式重启，不盲目续接不同文件。

资源放 Application Support 的 manifest-hash 版本目录，排除 iCloud 备份。
只激活一个验证通过的版本；新版本验证完成前保持原有资源。损坏/空间不足/
取消下载回到系统朗读，不损坏书籍/进度。允许用户删除模型/缓存；删除前停止
相关合成和句柄占用，删除 App 自有准确目录，不触碰导入原件或其他任务文件。

## 有界音频与进度

预缓冲建议 2–3 个短块，时间上限约 90 秒、磁盘上限 30 MiB，任一达到即停。
保留正在播放和必要的刚播片段，逐块 LRU 回收；不提前合成整书。缓存键包括
书籍指纹、章节/anchor、精确文本 hash、模型 manifest、speaker、速度、格式。
只有播放器已经实际播到的位置才落盘；预取完成不能推进“已听”位置。

暂停/恢复持久化 anchor + chunk audio offset；seek 取消过时预取；换声保留文本
位置。损坏或失败只丢弃对应缓存块；通过原有 Apple provider 从相同 anchor
回退，不从书头重播。需补充真实的换声、调速、取消、音频中断/耳机测试。

## 后台并非已解决

背景音频 entitlement 只说明音频会话能力，不能证明锁屏后 ML 合成可无限继续。
先测真机前台首段/稳态 RTF 与 RSS，再测预缓冲耗尽、锁屏 10–15 分钟、来电、
蓝牙和恢复。若合成被暂停，需要准确保存队列/位置并提供系统朗读回退；不能
伪造无限后台计算。当前电池、发热、device performance、锁屏行为均 NOT_RUN。
