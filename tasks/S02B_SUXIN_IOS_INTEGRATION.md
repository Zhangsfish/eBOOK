## 实施顺序

1. **原生文字到音素。** 实读固定作者前端，移植中文数字/日期/时间、标点、语言
   分段、多音词、词组最大匹配、声调/一不变调、特殊字与 PAD 规则。
   用真正作者前端导出的原创测试用例逐 ID 校验，覆盖训练外文本；不能仅靠五条
   预计算 ID、单字拼音或手填音素宣称支持任意书籍。单独验证中英混读；若需降级，
   明示适用范围和回退，不能静默丢字或替换音色。
2. **真实图适配。** 从已验证桥移植最小必要代码到正式运行时，补齐错误、内存、
   线程与取消处理；复用一个受控模型 session，禁止在主线程加载/推理。
   核验真机 arm64 和模拟器 slice、全部运行时/词典通知；不得用假波形验收。
3. **尽早出声且连续。** 初始请求使用保留语义/标点的较短块，后续有界预取，
   以 PCM 队列连续播放；不等一整章生成完成。队列与缓存设上限，控制 CPU/内存。
   缓存身份含模型/前端版本、文本摘要、声音和合成设置；不要跨版本误用。
4. **接入现有 App。** 在原有音色设置中提供“苏心”，保持 Apple 系统语音可用。
   保留 `SpeechProvider` 或提供兼容适配；处理准备中/失败状态、暂停、继续、变速、
   按段/章节跳转、从阅读位置开始与独立听书位置。跳转和切书取消旧任务，迟到的
   合成结果及回调不能播放或覆盖新位置；隐藏控制面板不影响朗读。
5. **测量而后决定。** 用未预生成的原创长文，在已识别的 iPhone 上完成下面的
   首声和连续播放检查。针对实际瓶颈做有界优化；未经用户否定不再次泛找模型。
6. **第一版交付。** 完成构建/回归、资源及分发材料核对，提交可独立审查的结果。
   审查通过后复用现有 eBOOK 签名和内部 TestFlight 流程提供手机更新，记录确切
   build 与源码。无需等待 PR #11。不得把 unsigned IPA 说成已可直接安装。

## 验收与证据

以下是实施目标，**尚非测得结果**。如实记录超标值及具体影响，不擅自改阈值来报通过。

| 项目 | 验收目标 |
| --- | --- |
| 模型已就绪，点播放 | 实际首声 p95 ≤1 秒；记录样本数和百分位方法 |
| 新进程、未缓存音频 | 实际首声 ≤3 秒，包含模型/前端/音频会话初始化，安装下载另计 |
| 跳到未缓存位置 | 实际首声 p95 ≤1.5 秒；旧内容不得继续响起 |
| 连续播放 | 1.0× 和 1.5× 各 30 分钟，无合成饥饿、丢句、重复或非文本停顿 |
| 速度与负载 | 报分块 RTF 分布/尾部、缓冲量、欠载次数、峰值内存、热状态与耗电观察 |
| 手机行为 | 界面响应、锁屏/后台、耳机控制、电话中断、蓝牙变化、重启后听书位置 |
| 读音与音色 | 原创小说长听，覆盖数字、年份、多音字、专名和混读，用户认可实际 App 声音 |

首声从用户操作到设备实际音频输出测量；合成完成时间和模拟器混音器探针另列。
不得用提前生成整段测试音频掩盖吞吐；自然标点停顿和缓冲欠载分别记录。

回归需覆盖原有阅读/导入/目录/设置/位置测试，以及取消竞态、缓存失效、模型资源
缺失、原生前端一致性、连续队列等真实风险。Xcode 生成文件必须与生成器一致。
模型/词典/运行时的实际随包文件及所需许可材料应列明，私下试听已有的根许可声明
不能替代最终整包核对；无需因此停止独立的本地集成工作。
